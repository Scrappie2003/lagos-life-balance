# Lagos Life — Personal Balance Editor

Your own editable Lagos Life inspired sim. Set your naira balance to whatever you want (starts at ₦1 billion).

**Not connected to the official https://lagoslife.app** — that is a closed-source multiplayer game with server-side balances. This is a local personal version you fully control.

## Play it
1. Open `index.html` directly in your browser, or
2. Enable GitHub Pages (Settings → Pages → Deploy from main / root) then visit:
   `https://scrappie2003.github.io/lagos-life-balance/`

Balance is saved in your browser's localStorage. Edit freely via the buttons or by changing the code.

Created for personal use / balance tweaking experiments.
